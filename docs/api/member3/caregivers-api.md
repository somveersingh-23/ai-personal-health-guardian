# Member 3 Caregiver Consent API

Creates opaque caregiver links with explicit two-party consent. Invited
caregivers may accept or decline; either active party may revoke. No raw phone
number/email is stored and no invitation or alert is externally delivered.

Endpoints: `POST/GET /api/v1/member3/caregivers` and
`POST /api/v1/member3/caregivers/{id}/decisions`.
